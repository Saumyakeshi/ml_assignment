# Documentation Index

Use this directory as the project's long-term knowledge base.

| Area | Purpose |
|---|---|
| [Lectures](./lectures/README.md) | Structured notes generated from lecture videos |
| [Assignment](./assignment/README.md) | Planning notes and requirement tracking |
| `decisions/` | Short records explaining important dataset, model, and evaluation choices |
| `research/` | Literature reviews, paper notes, useful links, and dataset investigations |
| [Templates](./templates/lecture-notes-template.md) | Reusable formats for consistent documentation |

When adding a document, link it from the nearest index instead of leaving it discoverable only through the file tree.
