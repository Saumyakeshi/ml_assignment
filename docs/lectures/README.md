# Lecture Notes Index

This directory contains Markdown notes generated from lecture videos. Organize files by teaching week:

```text
lectures/
|-- README.md
|-- week-01/
|   |-- lecture-01-topic.md
|   `-- lecture-02-topic.md
`-- week-02/
    `-- lecture-03-topic.md
```

Use lowercase kebab-case names and prefix them with the lecture number. For example:

```text
week-03/lecture-05-decision-trees.md
```

Copy the [lecture note template](../templates/lecture-notes-template.md) when creating a note.

## Note-writing rules

- Record the video title and source before summarizing it.
- Separate statements made in the lecture from your own interpretation.
- Preserve formulas, definitions, examples, and warnings accurately.
- Include timestamps for important explanations when available.
- End with explicit links to the relevant assignment section or implementation module.
- Put unresolved questions in the note instead of silently guessing.
