# Assignment Documents and Planning

The authoritative assignment files are stored in this directory:

- [Assignment information](./ASSIGNMENT_INFORMATION.md)
- [Original assignment brief](./COMP70049-Assignment.pdf)

Use this directory for supporting planning documents such as:

- `requirements-traceability.md` - maps each marking requirement to code, results, and report sections.
- `submission-checklist.md` - final verification before uploading to Blackboard.
- `report-outline.md` - planned allocation of the 3,000-word limit.
- `experiment-register.md` - concise index of completed experiments and results.
