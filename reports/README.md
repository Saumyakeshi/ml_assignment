# Report Artifacts

- `drafts/` contains the working report source and outlines.
- `figures/` contains final charts referenced by the report.
- `tables/` contains final comparison tables and metric summaries.
- `final/` contains submission-ready documents.

Use stable names that identify the assignment section, model, and result. Examples:

```text
figures/section-01-logistic-regression-confusion-matrix.png
figures/section-03-autoencoder-precision-recall-curve.png
tables/section-02-model-comparison.csv
```

Keep exploratory plots inside notebooks; copy only report-ready versions here.
